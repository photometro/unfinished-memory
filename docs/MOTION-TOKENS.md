# Unfinished 动效与触摸反馈规范

v0.4.0 将 UI 原型中的“卡片跟手、飞出、补位、进入功能页”收敛为一组可复用的动效 Token，入口位于 `MainActivity.kt` 的 `MotionTokens`。

## 动效 Token

- `easeOut`：普通布局补位与卡片回位，强调快速响应、柔和收尾。
- `prototypeEase`：卡片详情页进入/退出，300ms 位移 + 180ms 淡入淡出。
- `flingEase`：卡片超过阈值后的飞出，280ms 完成，并在阈值越过时触发一次触觉反馈。
- `pressMillis`：触摸反馈 140ms，缩放到 0.97；只保留轻微物理反馈，不使用默认 Ripple。
- `selectionMillis`：选中卡片抬升、拉直和补位 250ms。

## 交互规则

1. 只有最前卡响应左右滑动；阈值为 `max(82dp, 卡片宽度 × 0.28)`。
2. 后两张卡在前卡拖动时只做轻微抬升与缩放，保持 D2 的紧密横向层级。
3. 卡片飞出后立即轮换卡组，原卡片回收到队尾，避免空位闪烁。
4. 卡片和设置行使用 `noRippleClickable`，按压时仅缩放，不出现黑色半透明遮罩。
5. 读取系统 `ANIMATOR_DURATION_SCALE`；用户开启“减少动画”时，保留状态变化与淡入淡出，关闭位移、飞出和弹簧动画。

## 验证要求

- 真机验证：点击卡片进入同色功能页、点击设置、按压卡片/设置行均无黑色遮罩。
- 真机验证：前卡左右滑动后飞出、后卡补位，连续操作不崩溃。
- 构建验证：Debug APK 编译、签名校验、安装并启动成功。
