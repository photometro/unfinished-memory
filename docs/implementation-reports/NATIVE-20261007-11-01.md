## 实施过程中发现的问题

### P-01 — AAPT2 受限执行时链接进程异常退出

- 现象与阶段：受限环境中的 Gradle 在 `:app:processDebugResources` 资源链接时失败；多次提示 AAPT2 daemon unexpected exit。
- 根因：具体原生退出原因未确定。证据表明同一隔离构建在沙箱外执行后资源链接通过，故不能归为资源或 Kotlin 代码缺陷。
- 影响：普通受限命令不能完成构建验证。
- 处理与验证：使用获批的沙箱外隔离构建，只运行 `-PprotocolTest`；`:app:compileDebugKotlin`、单元测试与 `:app:assembleDebug` 均成功。没有修改 Gradle／AGP／Kotlin版本，也没有改 wrapper 配置。

### P-02 — 真机截图期间屏幕休眠／锁定

- 现象与阶段：魅族21上的初次截图为黑屏；系统状态显示 `Dozing`。唤醒后只显示系统锁屏，不是应用页面。
- 处理：没有绕过锁屏。临时锁屏截图从工作区及设备删除，未保留通知内容。应用进程仍在前台，未观察到崩溃；但这不构成 UI 正常渲染证据。

### P-03 — API33设备拒绝隔离安装

- 现象：魅族18s（API33）返回 `INSTALL_FAILED_USER_RESTRICTED`。
- 影响：API33真机运行时验证未完成；正式应用未被安装或覆盖。
- 恢复条件：用户允许魅族18s本次USB安装后，仅重试 `com.unfinished.app.protocoltest`。
- 后续解决（2026-10-08）：用户批准使用新并存包名；魅族18s API33已成功安装 `com.unfinished.app.native11test` 与仪器包，未重试覆盖安装旧协议包。

### P-04 — 已安装隔离包与新候选的调试签名不同

- 现象：魅族21已存在 `com.unfinished.app.protocoltest`，安装本次新APK返回 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`。
- 影响：设备保留的是先前安装的隔离测试版本；本次最新候选仅在工作区构建成功，尚未安装，因此当前不能用它做真机视觉验收。
- 处理：没有卸载、清除旧测试包数据或改动正式 `com.unfinished.app`。未找到／替换匹配签名；等待用户确认采用可并存的新隔离包名或其他安全安装方案。
- 后续解决（2026-10-08）：用户批准使用新并存包名；魅族21 API36已成功安装 `com.unfinished.app.native11test` 与仪器包，旧 `protocoltest` 和正式包均保留。

### P-05 — 首页非主按钮的内容测量挤掉主按钮

- 现象：首次安装新候选后，魅族21截图与仪器测试均显示「过去」占满整行，「留下一段」虽在源码中却没有可见宽度。
- 根因：横向 `Row` 中，「过去」没有权重；`GlassAction` 内部内容行使用 `fillMaxWidth()`，无权重子项先按剩余最大宽度展开，将主按钮挤为零宽。这是通用 Compose 测量关系，不是魅族21专属问题。
- 修正：两个操作都参与比例测量，主按钮 `weight(1.2f)`、次按钮 `weight(0.8f)`，按可用宽度分配约60%／40%，保留原型顺序与主次关系。
- 验证：修正前双机同一自动化断言失败且魅族21截图只有「过去」；修正后 API36/API33 两机的可见性／相对次序／间距测试均通过，魅族21新截图同时显示两个按钮。未改业务回调或设备条件。

### P-06 — 自动入场后开屏仍保留重复动作按钮

- 现象：自动退潮已接入，但开屏右上仍显示「抵达岸边／略过」，造成重复入口。
- 修正：移除该按钮及其手动跳过分支；保留自动退潮、图片等待上限与减少动画的同终态路径。
- 验证：真机 Compose 测试断言两种按钮文案均不存在，并等待 `onEntered` 自动触发；API36/API33各通过。
