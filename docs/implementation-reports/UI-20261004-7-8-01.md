## 实施过程中发现的问题

1. 原生日期 DOM 值变化后未同步 React 草稿。使用共享 onInput／onChange 处理后，日期在辅助页返回和确认中保持一致。
2. pending 期间工作室／构图快捷键仍可切页。独立审查指出后，补上 fieldset／按钮禁用、commitLock 与键盘守卫，浏览器复查禁用状态。
3. 旧焦点轮廓仍是暖棕色。统一为 R2 功能 action token，包括搜索框。
4. 保留 `.review-page`、`review-seal` 接口并在成功、重置草稿前捕获。日夜快照保留正文、页根色和实际非零滚动位置。
