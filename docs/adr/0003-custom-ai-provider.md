# ADR-0003：复用观己自定义 AI 提供方

## 状态

已接受

## 背景

用户希望复用“观己”已有的自定义模型配置，同时避免把私人记忆原文放入“未完成”业务服务器。

## 决策

App 提供 Base URL、Model、API Key 和连接测试。使用 OpenAI Compatible `/chat/completions` 协议，AI 请求从设备直接发送到用户指定的提供方。AI 只生成可编辑 Cue 建议，不能参与浮现选择、情绪判断或原文修改。

## 后果

- 后端不接触 API Key。
- 未配置 AI 时仍可手动完成所有核心流程。
- 必须在设置和线索页说明第三方模型可能接收用户主动提交的原文片段。
