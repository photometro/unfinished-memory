# 未完成_ App UI 原型

> PROTOTYPE ONLY：这是用于验证主页结构与交互的抛弃式原型，不是生产代码。

## 设计判断

这是一个面向个人记忆的移动端核心 App 原型。视觉语言安静、私人、有纸页层次，同时保持现代感。

- DESIGN_VARIANCE：7
- MOTION_INTENSITY：5
- VISUAL_DENSITY：3
- 设计基础：原生 HTML、CSS、JavaScript
- 色彩方向：冷灰档案感；“留下”暖灰、“遇见”冷青、“过去”档案蓝灰分别承担空间身份
- 首页信息层级：三张功能卡片承担主体导航；顶部只保留轻量设置入口，安静状态不显示常驻文案
- 顶层导航：无 Tab 栏；有记忆浮现时，顶部临时出现“有一页回来”状态入口

## 本轮要回答的问题

三张大卡片如何承担一级导航，并把“留下、遇见、过去”连接成完整的记忆回顾流程？

## 三个方案

- A 垂直叠页：层级最清楚，默认推荐方向
- B 错位索引：更具编辑感，卡片左右错开
- C 扇形卡组：物理感最强，视觉辨识度最高

通过底部工具条或键盘左右方向键切换方案。URL 会同步保存 `?variant=A`、`?variant=B` 或 `?variant=C`。

“切换浮现状态”用于比较：

- 安静状态：留下卡在最前方
- 一页已回来：遇见卡移动到最前方

## 运行

双击 `index.html` 即可。

或者运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

## 可操作内容

- 点击任意层级卡片进入对应功能
- 拖动最前面的卡片，查看跟手移动、阈值确认、惯性飞出和卡组循环
- 留下一段：自动保存、AI 默认建议线索、用户确认/编辑、选择浮现方式、确认封存
- 遇见过去：主动遇见、打开浮现、暂缓
- Recall：逐级提供线索、选择记忆状态、提交当前回忆
- Reveal：对照“后来记得的”和“当时留下的”
- Reflection：留下现在的回应，或选择不回答
- 很久以前：年份搜索、记忆时间线详情
- 设置：主动浮现、浮现通知、本地锁、隐私说明
- 按 Esc 返回主页

## 当前交互规则

- 点击任意卡片可以直接打开对应功能
- 只有最前面的卡片响应左右拖动
- 左右滑动只用于切换主卡，不代表删除、拒绝或暂缓
- 卡片越过约 28% 宽度的阈值时会触发一次轻微触觉反馈（浏览器支持时）
- 没有越过阈值时，卡片会回弹到原位
- 越过阈值后，卡片飞出并回到卡组底部

## 核心页面流程

```text
首页
├── 留下
│   ├── 写下内容
│   ├── 自动保存 / 保存并退出
│   ├── AI 建议 Cue（可编辑、移除、新增）
│   ├── 选择浮现方式
│   ├── 封存确认
│   └── 封存完成
├── 遇见
│   ├── 主动遇见
│   ├── Recall
│   ├── Cue 逐级揭示
│   ├── Reveal
│   └── Reflection
├── 过去
│   ├── 年份搜索
│   └── Memory 时间线
└── 设置
    └── 隐私与浮现控制
```

所有数据只存在于当前页面内存中，刷新后恢复默认状态。这个原型用于验证产品体验，不连接后端，也不代表最终 Android 代码结构。
