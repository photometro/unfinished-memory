## 调整

- 在上一版矢量基础上，平台导出缩放系数乘以 0.94，主体宽度缩小 6%。
- 缩短各片的纵向高度，并分别补偿两道间隙，让合并轮廓宽高比由约 0.86∶1 变为 0.96∶1。
- 总体高度相对上一版减少约 15.9%，包括等比缩小与近方形调整；不是宣称宽高都只减少 6%。
- 不把调整后的图形重新撑满安全区。主体距 66dp 安全圆边缘的余量约 3.98dp。
- 横向坐标、三片左右对齐关系、排列顺序和三层海蓝不变；没有新增文字、装饰或材质。
- 不通过把两道间隙压紧来取得近方形轮廓。中轴间隙约为 1.8dp / 1.7dp，比单纯纵向压缩保留了更多空间。
