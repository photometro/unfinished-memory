# 未完成 · 六款图标对比

产品核心：留下文字、照片和生活片段，安全封存，在未来重新接近曾经的自己。图标用保存记忆的物品代指核心行为，海岸与洋流负责连接 UI，不要求用户先理解算法。

## 方案

- **A · 翻开的照片**：留下片段 → 照片 → 纸面翻角。照片承载瞬间，翻角表达重新打开。
- **B · 记忆册**：记录与回看 → 册子 → 纸页层叠。强调私人记录与回看，纸页中保留海岸。
- **C · 漂流瓶**：封存与再遇见 → 瓶中纸片 → 半透明玻璃。突出保留、漂泊与未来的遇见。
- **D · 错位照片**：保存瞬间 → 照片 → 局部错位。拆开一个角，让画面未完全闭合。
- **E · 潮页记忆册**：重读过去 → 册子 → 双页错位。纸页化成色面，用海岸线连接两页。
- **F · 洋流记忆瓶**：封存与漂泊 → 瓶中纸片 → 洋流拆分。瓶身拆成深浅两股流面，纸片仍被保留。

A/B/C 是物品识别优先的一组；D/E/F 是物品不变、逐步解构的一组。三种物品也各有联想风险：照片可能像相册，册子可能像阅读/笔记，漂流瓶可能像瓶中信社交。它们只是品牌候选，不宜声称单凭图案即可准确识别全部功能或产品名称。
