## 适配边界

原图的白色圆角底板与外侧黑色不能直接作为自适应图标层，否则可能出现二次边框。透明前景和纯白背景分离，裁切由系统负责。

整体最大实色半径为 31.72dp，小于 33dp 安全圆半径；本次统计超出安全圆的 alpha>16 像素为 0。蓝色合并轮廓与两个独立黄色轮廓均存在。未额外调整黄色/蓝色面积比例。

imagegen 的背景提取不是像素级确定性抠图。它保留选择的视觉方向，但边缘与微小颜色变化不承诺逐像素等同原图；已保留原图供复核。本轮不以提取效果作为新的设计方向。

单色图标会合并两个相互重叠的蓝色体，两个黄色点的轮廓仍在；本轮仅做资源预览，未修改真机主题图标设置，也不声称所有主题均已验收。
