# C · 存片 — 间隙回调 v5

用户认为上次 v4 间隙过小，本轮从 v3 宽版重新编辑。使用内置 imagegen，而非程序重绘。三个版本仅用于同一方向的间隙对照，不是新的主体探索。

## 栅格辅助复核

1254×1254图像，中心x=627的两道间隙：

| 版本 | 上间隙 | 下间隙 |
| --- | --- | --- |
| v3 原间隙 | 34px | 33px |
| v4 上次过紧稿 | 22px | 20px |
| v5 回调稿 | 25px | 24px |

v5比过紧稿放宽3px和4px，介于v3与v4之间。提示词希望接近31px/30px，但生成工具没有精确执行；不能宣称已精准达成8%～10%的收紧比例。保留本稿作为视觉审核，不自动宣布定稿。

本轮保持三段、左右对齐、弧形间隙及浅至深配色关系。但生成式编辑存在轻微轮廓和色彩漂移，不承诺各色块尺寸和色值逐像素相同。后续精确源文件需要单独制作，尚未纳入本轮。

已生成48/64px与圆形/圆角整图裁切对照。原稿保留，未更改App原生资源、未构建安装、未做品牌识别测试或真机验收。中间v4版本只用于过程比较。

PROMPT.md保留本轮完整提示词；gap-audit.json保留多列像素间隙检查；build-preview.cjs仅机械缩放与拼版。
