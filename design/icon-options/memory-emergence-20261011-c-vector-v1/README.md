## 本轮的改变

保留已选 C-gap-v5 的三片对齐形体、两条开放的曲线间隙和由浅到深的海蓝色。只做有限节点的 Bézier 矢量重绘与桌面视口归一化，不继续拉伸、不收紧间隙、不增加新符号。

生成图片中的轻微颜色和边缘波动被收敛为固定曲线、固定色值。本稿是忠实重绘，而非逐像素自动描摹；重绘与参考的并排对照位于 `comparison.png`。

图形等比放入 Android 图层的中央安全区，再以可见视口预览，改善原大图里主体偏小的问题。这是平台画布映射，不是改变三个色块的长宽比。准确比例、间隙、安全区和裁切检查见 `asset-qa.json`。

## 文件

- `mark-source.svg`：1254 坐标系、三个有名称的可编辑路径，是形状的唯一来源。
- `spec.json`：固定色值、平台尺寸和本轮约束。
- `icon-master.svg`：108dp 完整自适应图层画布。
- `foreground.svg` / `background.svg` / `monochrome.svg`：独立图层。
- `icon-visible.svg` / `icon-1024.png` / `store-512.png`：72dp 可见视口的无裁切圆角、无阴影版本。
- `color-48.png` / `color-64.png`：实际桌面像素大小。
- `circle-*` / `squircle-*` / `rounded-*`：不同裁切的模拟图。超椭圆不是对任何特定 OEM 形状的保证。
- `safe-zone.svg`：安全区检查示意，不是发布图标。
- `desktop-simulation.png`：浅色、深色、沙色壁纸及主题着色对照；邻居为通用占位图形，不是现有产品，也不是真机截图。
- `android-candidate/res/`：独立命名的 Android 候选资源，未改变当前 `ic_launcher`。
- `index.html`：本地评审页，无联网依赖。
- `build-assets.cjs`：读取源 SVG，机械导出平台资源和模拟图，可重复生成。

Android 候选资源名为 `ic_launcher_fragment`，刻意与当前资源隔离。`v26` 版本含前景和背景；`v33` 版本补单色层；另有五档密度的传统 PNG。后续如获准采用，才修改正式工程的图标引用。

## 平台依据与限制

按 [Android 自适应图标官方指南](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive) 使用 108×108dp 图层，关键形体放入中央 66dp 安全区，保留外圈空间，不在发布资源里烘焙外圆角或外阴影。图层优先采用矢量，主题图标提供单色层。

静态模拟不能代替 Launcher 的实际遮罩、主题配色、图标缩放或用户识别测试。资源编译验证与形状检查不等于真机验收。不得把“能看清三片”解释成“陌生人能猜出未完成这个名字”。

## 后续验收

1. 用户确认重绘没有丢掉当前版本喜欢的比例与间隙，且桌面占比合适。
2. 获得替换/安装授权后，检查真机圆角、桌面实际大小、不同壁纸和主题图标；不提前覆盖当前版本。
3. 简短识别测试：大概是什么类别的 App、能否再次找到、是否和其他图标混淆。类别与具体品牌识别分别记录。
