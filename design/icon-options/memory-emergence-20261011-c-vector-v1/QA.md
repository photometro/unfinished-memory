# 候选资源验证 / 2026-10-11

## 已验证

- 源文件只有三条具名路径，没有外阴影、纹理、文字或烘焙平台裁切形状。
- 前景、单色 SVG 与 Android VectorDrawable 共用同一份路径数据；三层颜色固定。
- 等比缩放后的主体约 46.49×54.12dp，保留原长宽比，最远轮廓点距画布中心 32.85dp，位于中央 66dp 安全圆内。
- 中轴两道间隙约 1.9dp / 1.8dp；不同分辨率下的测量有栅格量化差异。
- 圆形、近似超椭圆、圆角方形模拟遮罩均未裁掉实心主体像素。附加裁切组造成的少量抗锯齿边缘差异单独记录，不伪装为零像素差异。

- 使用本机 Android SDK 35 的 AAPT2 执行候选 `res` 编译与链接，成功包含前景、背景、单色层、v26/v33 自适应资源及五档 PNG 密度资源。
