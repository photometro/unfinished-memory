# 未完成 · 潮汐字标图标草稿

这是图标方向预览，尚未替换 App 的启动图标。

主识别直接使用「未完成」三个字，采用项目已有的 Noto Sans SC 字体。蓝色基底与底部宽幅海水层次衔接现有潮汐视觉；字标下方的断开潮线呼应产品原有的「未完成_」命名。

- `icon-1024.png`：完整方形图稿，供后续裁切与适配。
- `icon-48.png`、`icon-64.png`、`icon-96.png`：按真实像素尺寸输出的识别检查。
- `icon-monochrome.png`：去掉色彩层次后的字标检查。
- `preview.png`：大图、小尺寸、圆形裁切与黑白对照。
- `index.html`：本地预览入口。
- `icon.svg`、`render.cjs`：可继续调整的图稿与渲染脚本。脚本从当前项目的嵌入字体文件加载字形，再由 Sharp 输出位图。

当前目视检查：48px 和 64px 下名称仍可辨读；圆形与圆角裁切未切掉名称。尚未进行真机桌面验证。
