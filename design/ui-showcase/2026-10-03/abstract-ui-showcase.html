ABSTRACT TIDAL LANDSCAPE抽象版 · UI 设计展示

设计方向 / 机制抽象 · 留白 · 地貌隐喻

把时间，转译为潮沟。

暖沙白与雾蓝灰构成安静的岸边。
潮水退去，记忆在留白中重新显露。

设计理论 / DESIGN RATIONALE

不画一棵树。
表达一片被水
切开的滩面。

以形态、层级与负空间传达时间的痕迹，让景观为记忆内容服务。

01机制抽象，而非纹样装饰

细沟逐级汇入主沟，以向海增宽的连续水道表达关系；沟岸与湿滩形成轻微地形层次。

02用留白建立信息层级

上部承载当下状态，下部展开潮滩。正文与操作以字重、间距和单一强调色区分。

03退潮是一种显露叙事

开屏降低示意水位，显露已有沟槽。阅读与书写回到安静表面，支持减少动画。
