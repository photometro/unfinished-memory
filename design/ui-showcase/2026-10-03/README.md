## 内容与来源

屏幕内容直接截取两版现有原型的实际渲染，不通过图像生成模型重绘。主屏幕保持完整比例，未裁掉界面；底部明确标注为“原型局部”的缩略图使用裁切，只用于构图或光照展示。手机外缘是展示板的轻量框架，不属于 App 界面。

- 抽象版来源：`../../tidal-tree-prototype`（实际目录：`design/tidal-tree-prototype`），当前排水/切沟代理模型，构图 A 为主要展示。
- 真实版来源：`design/tidal-realistic-prototype`，四时段原型，构图 A、中午为主要展示。
- 截图由隔离的、启用沙箱的 Microsoft Edge 获取，设备像素倍率为 2，系统减少动画开启。导出展示板只读取本地素材，不联网。
- “留下”页填入的是展示用虚构文字，仅存在于该隔离预览的 RAM 中，关闭后丢弃。未读取原生 App 或真实用户记录。
- 色板用于概括视觉语言，不表示截图中所有像素遵守固定色值。真实版包含生成环境素材，不是实际航拍摄影；两版均不是科学潮汐模拟。
- 设计说明区分意图与原型状态：真实版四时段目前手动选择；正式素材一致性和 Android 真机性能尚未验收。

## 复现

两版预览需分别运行在 5188、5189 端口。可在各原型目录执行 `npm run preview`（需要已有构建）或 `npm run dev`。

在此目录执行：

1. `node capture-screens.mjs`：截取高清原型界面。
2. `node export-showcase.mjs`：加载两张 HTML，校验图片、中文字体、布局边界与运行错误，并导出 PNG。

脚本复用已有原型的 Playwright，未安装依赖。中文字体为 Noto Sans SC，OFL 许可见 `assets/NotoSansSC-OFL.txt`。

本次只新建 `design/ui-showcase/2026-10-03`；不修改两版原型的源码、原生 App、核心算法、待办列表或 Git/GitHub。
