## 页面与页内层级

- 首页底部只有「留下一段 / 过去」，不新增洋流按钮。
- 主要功能打开完整页面，无内缩、独立圆角卡片或黑色遮蔽；手机外框不是页面卡片。
- 书写正文优先，来源与草稿为辅助动作，错误贴近输入。
- 四步：写下仅正文、留线索仅提示、怎样回来选择方式、收好只读确认；每页单一主任务。
- 所有下一步／跳过均不是提交，暂存也不是封存。空白暂存禁用，空白下一步定位正文输入。
- 出现方式三项纵向单选，解释紧随对应名称；日期仅在「某一天」时出现。不用三列塞入长说明，窄屏与键盘切换仍正常。
- 线索建议默认可见但不自动采用，可以采用、移除、自己写与修改；不要求用户先填线索才能封存。
- 背景与偏好独立可选完整页；背景从线索进入，偏好从出现方式进入。即时保留输入，箭头／Escape／完成返回原步骤。静存隐藏无效偏好入口，不销毁旧选择。
- 普通内容和输入透明，不叠书写板／原文板／建议色块；功能页头、内容、页尾同一整页底色。少量语义分界配合留白，不加卡片或阴影。
- 长原文随整页滚动，不出现嵌套的狭小原文滚动框。
- 回忆问题、回忆输入与主动索取的线索有不同层级；不会默认泄露原文或全部线索。
- 阅读「当时留下 / 这次想起 / 现在回应」分别成组，原文不被回忆覆盖。
- 回应保存后收起编辑区，已存文字只呈现一次，仍可继续添加新回应。
- 设置先操作、后解释，光照与舒适度为独立分组，说明文字不与主操作等权。
- 内容整体滚动，页头、主动作稳定；留意长正文、空结果与增加线索的布局。

## 封存、洋流与纸船

- 封存不展示真实海面或波纹，采用纯灰蓝背景与哑光暖白纸船。
- 纸船有明确的船舷、中央折面与内侧阴影，无桅杆、旗帜、粗描边、玻璃透明感或情绪配色；小尺寸仍能辨认。
- 成功后先保留整张确认页及滚动位置；收拢与翻折同步，蓝色从背后露出，不先清空控件、完成页面缩略图或另外出现空白纸。
- 原文保持原换行与滚动位置，直接映射到相连折面的印刷正面；随面转向背面/被覆盖而藏入纸内，不通过正文先淡出或白色蒙层盖住来冒充封存。
- 同一组十个折面连续形成三角折片、船舷与中央折面，直到漂泊结束均不换成另一艘船；只有离开视线时整艘船渐隐。船内阴影在后段建立，不提前像十块彩色碎片。完成船身没有可读原文或照片。
- 页面副本只用于瞬时动效，惰性、对辅助技术隐藏、无重复字段 ID，不是新导航层或可操作弹窗。
- 关键姿态为艺术化压缩，不声称完整物理折纸；标题和流迹在翻折后段露出，完成文案不提前出现。
- 主流横穿画面，局部涡旋偏离中心；短流迹具有疏密与明暗变化，不像两束绳索交叉打结。
- 普通封存：原页边缘翻起并收拢 → 正文被折面收进去 → 两角收合 → 船身展开 → 停稳 → 顺流远去 → 渐隐 → 蓝色完成状态。
- 完成页保持洋流连续流动，不随纸船完成而停止；返回岸边才结束环境。减少动画仍为静态，静存仍不显示流场。
- 载体与流迹采样同一流场，切向旋转平缓，路径不经过底部按钮；淡出只表示离开视线，不表示销毁。
- 成功提交后才播放；失败不新增、不清空草稿、不播放成功动效。
- 跳过只结束动画，记录数量不再增加；重复确认有提交锁。
- 静存：同样折成纸船并保留，无漂泊、无流迹；在过去可主动查看。
- 减少动画直接呈现完成状态和静态画面，不改变提交结果；动效中启用也直接结束，关闭后不重播已经完成的仪式。
- 上岸和过去使用同一形态、材质与记录 ID，SVG 材质 ID 不互相冲突；不用海上位置作概率或进度。
- 左侧纸船与洋流观察仅是设计检查，不混入 App 首页导航。
- 连续运动不逐帧更新 React 状态；Canvas 在文档隐藏时暂停，卸载时清理。漂泊使用 transform/opacity，折叠阶段重绘 SVG 折面和印刷矩阵；不把十份 DOM 视觉副本当成已验收的生产性能方案。
- 减少动画首次打开也先测量容器，完整静态船不闪到左上角；不依赖页面快照才能定位。
- 载体起点与淡出区域根据页头、页尾实际尺寸调整；短屏不挤压说明或按钮，不用设备型号常量。

## 操作与控制权

- 空白书写验证、暂存与恢复草稿、返回书写均保留输入。
- 来源补记区分发生时间与记录时间，情境字段可留空。
- 指定日期缺失时停留提示，不进入成功场景。
- 局部选项支持取消/完成、Tab 焦点约束、Escape 关闭与焦点回返。
- 页面入场结束不抢占已经进入的字段焦点；校验错误位于相关输入或底部主按钮附近，提交失败不制造空白页。
- 上岸保留想一会儿、再给一点、直接看看、暂缓四种出口。
- 主动要线索前保留非空回忆，揭晓前锁定；直接查看没有空白快照。
- 想不起来停止追问，仍可查看/暂缓；暂缓不自动揭晓或赋予算法时长。
- 回应在本次内存中保留；过去搜索、空结果、清空、筛选与阅读返回正常。
- 四时段与构图切换不清空当前输入；设置减少动画/降低透明度可预览。
