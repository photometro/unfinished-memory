## 纸船、折叠与洋流

载体改为原创哑光纸船：略俯视的斜侧构图，暖白不透明纸面、两端尖、中央隆起折面、内侧阴影与轻薄船舷。不是纸船线条图标，不添加桅杆、旗帜、粗描边或发光边缘。界面玻璃控件不变，纸船本身不使用玻璃材质，不按情绪或重要性着色。

保存成功后，本地保留当前确认页的惰性 DOM 视觉副本，连同原文换行、输入值与滚动位置。确认页与仪式共用稳定路由宿主，不先退出/淡出原页面。十个相连的三角折面最初铺满整页，每个印刷正面裁切同一份页面副本；共享边和中心顶点在全过程持续相连。上半页绕中线翻起，原文跟随自己的折面变形，转到背面后被遮住；随后两角收合成三角折片，船舷和中央折面逐步展开。收拢与翻折同步，不先完成一个页面缩略图。只有这组原折面继续停稳、漂泊与渐隐，没有白色蒙层、空白纸换场、独立小纸层或页面/船对象交替淡入。背面先延续原页面色，再逐渐成为暖纸材质，船内阴影在后段建立。

这是相连折面与原创关键姿态的艺术化折纸研究，不是完整传统折法、刚性纸张物理或严格等面积模拟。它用来检验「同一张纸」的可感知连续性；是否自然仍需看动态实样，不能仅凭同一组件或构建通过判定。上一轮的纸船结构参考保留在历史文档中，本轮没有复制教程图像。

洋流参考真实洋流可视化中的整体流向、局部涡旋与粒子轨迹关系，再做艺术化简化。主流从左下向右上穿过画面，两处不等大的局部涡旋偏离中心；分散的短流迹以不同长度、密度和明暗随连续流场推进，不再绘制三组固定交叉曲线。参考：[NASA Perpetual Ocean 2](https://svs.gsfc.nasa.gov/5425/)。这里没有使用真实地理数据，不声称物理准确。

普通封存约 5.5 秒（提交等待另计）：保留原页 0.18 秒 → 翻起并收拢 1.1 秒 → 两角收合 0.65 秒 → 三角折片成形 0.55 秒 → 船身展开 0.65 秒 → 停稳 0.22 秒 → 漂泊渐隐 2.1 秒 → 蓝色完成状态。前段不提前清空页面；仪式标题、按钮和流迹在折叠后段显现，完成文案不提前出现。载体与流迹采样同一流场，位置按实际容器及页头/页尾尺寸计算，静态载体在首帧前测量，不使用设备型号定位。视觉运动不表示浮现概率、航线、倒计时或到岸进度，时长仍是试样。

纸船离开后，完成页的洋流持续流动，直到用户返回岸边；船的动画结束不等于环境动画结束。`journey-state.js` 独立声明流场的活跃阶段，完成状态也包含在内。减少动画仍是静态流场，静存不展示流场，文档隐藏时暂停、退出时清理。

折船复用现有 React / Motion / Canvas，不增加 3D 引擎或新依赖。本轮新增的母图只用于首页环境候选，与折船无关。首折用三维旋转与透视投影，后段为连续顶点关键姿态；SVG 裁切与仿射矩阵让正文跟着折面走。十个瞬时 DOM 副本只在原型中作为印刷面的绘制方案，不能直接当成原生实现方案。没有逐帧 React 状态更新；折面和印刷矩阵会重绘，不声称全程 GPU 加速或已通过性能/原生验收。静态纸船与仪式最终姿态共用同一几何及材质定义。

## 四步操作与功能色

1. 写下：仅正文。空内容阻止下一步，暂存返回岸边；暂存与所有下一步都不封存。
2. 留线索：建议默认可見，可采用、改写、移除或跳过。未采用建议不写入自留线索。背景可留空。
3. 怎样回来：偶然遇见／留给某一天／静静保存。指定日期在这里校验，只有选择它才出现日期；偏好仅在非静存时可选，切换政策不删除旧日期或偏好。
4. 收好：只预览原文、线索、来源、背景和出现方式，展开原文不增加设置。最终确认是唯一提交入口。等待禁用返回、提交与外部演示导航，失败原页留稿，成功捕获实际页面再进入已认可折船。
