## 当前版本：从汇流关系生成潮沟

先检索一手论文，再替换形态模型。研究事实、设计转译和科学边界见 [TIDAL-FORMATION-RESEARCH.md](./TIDAL-FORMATION-RESEARCH.md)。

- 移除预设主干、固定分枝数量、左右轮流分叉与递归角度。
- 定义低坡度潮滩的构图包络、海岸与海口。固定种子生成不规则平面网格和空间阻力场；这不是钱塘江实测高程。
- 在平面三角网格上求加权排水路径；汇流累计示意水量，经过两次导流反馈，筛出达到视觉阈值的沟段。不采用规则 D8 八方向线条。
- 沟宽由示意水量决定，沿向海路径递增；支沟与主沟共享交汇点，平滑只在沟段内部进行。沟岸、湿滩与沟心呈现凹入滩面的负空间。
- 同一模型派生示意切沟高度场。开屏降低水位来显露已有地貌；不是动画几秒内生成地形。终态仍保留沟水。岸边微动只画在海域与沟水里，不覆盖陆地。
- A/B/C 首页结构、淡雅配色、嵌入字体与演示操作保持原有方向。真实版、原生 App、V3 记忆算法与待办不改。

这是机制启发的**图形代理**：加权最短路径不是水面梯度求解，累计示意水量不是实测潮汐棱柱，视觉阈值不是剪应力，反馈不是水沙耦合。模型也没有模拟真实溯源侵蚀、沉积或完整涨潮阶段，不能称为科学潮汐模拟。
